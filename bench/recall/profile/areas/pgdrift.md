- [stated] pgdrift is a command-line tool that compares Postgres schemas between two environments and prints the migration needed to line them up
- [stated] Written in Rust; started in 2023 as a way to learn the language
- [stated] About 2,300 GitHub stars; licensed Apache-2.0
- [stated] Current release is 0.9.4; the 1.0 release is planned for February 2027
- [stated] Blocking 1.0: support for partitioned tables and a stable JSON output format
- [stated] Co-maintainer is Anselm, who handles the Windows builds
- [stated] Release branches are named release/x.y; tags are signed
- [stated] Works on it Sunday mornings, about three hours a week
- [stated] Sponsorships bring in about $140 a month, which pays for stickers and a test server
