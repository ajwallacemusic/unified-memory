# Judge prompts

These five grading prompts are taken verbatim from `src/evaluation/evaluate_qa.py` in the LongMemEval repository (https://github.com/xiaowu0162/LongMemEval, MIT licence, Wu et al., 2024), fetched 2026-11-10. The only change is that the three positional slots are named `{question}`, `{answer}` and `{response}`.

`default.md` is used for the single-session-user, single-session-assistant and multi-session question types.
